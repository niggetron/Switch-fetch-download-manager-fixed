# Native libraries

`arm64-v8a/libaether_core.so` is **generated by CI**, not committed to git.

The `.github/workflows/build-release.yml` workflow cross-compiles
`rust/aether-core` with `cargo-ndk` for `arm64-v8a` (minSdk 24) and writes the
result to `arm64-v8a/libaether_core.so` before invoking Gradle. Gradle picks it
up through the explicit `jniLibs.srcDirs("src/main/jniLibs")` entry in
`app/build.gradle.kts`.

Without the library the app still works: `AetherNativeBridge` falls back to the
Kotlin OkHttp engine. The Telemetry screen will then show the "not bundled"
label. To build locally, run `./rust/aether-core/build_android.sh` with a stable
Rust toolchain, cargo-ndk, and an Android NDK installed.
